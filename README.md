# Hi, I'm Liang Wang 👋

Final-year **BEng Biomedical Engineering** student at the **University of Dundee** (3+1 programme with Northeastern University, China), based in Dundee, Scotland.

I'm interested in **biomedical signal processing**, **embedded medical devices & wearables** and **medical imaging AI**: building the hardware that measures the body and the algorithms that make sense of the data.

🏅 2025 AIC Algorithm Innovation Competition: **Provincial First Prize** and **National Second Prize**

## 🔬 Current project
**Portable Sensor Pod for Real-Time Surgical Sabermetrics** (Honours Project, ME41002)
- LSM6DSOX IMU + ESP32-C3-MINI-1 wireless sensor pod
- Comparing FSR vs compression load cell for grip-force sensing
- Calibration, filtering and feature extraction: RMS angular velocity, smoothness, spectral energy, task completion time

## 🧪 Selected work
- **LLM-based ECG data augmentation** under extreme data scarcity: Gemini-generated synthetic ECG features constrained by clinical ranges, benchmarked on 5 classifiers (KNN, RF, LR, GBDT, DNN); GBDT reached accuracy 0.9833 with only a 5% real-data baseline (first-author paper)
- **EEG emotion recognition with TSception** (UCLA neuroengineering & BCI seminar, advisor Prof. Dejan Marković): lightweight 12,563-parameter network evaluated on DEAP and MAHNOB-HCI
- **Endometrial cancer PET/CT segmentation & detection**: built the ECPC-IDS dataset and DC-TransUNet (TransUNet + attention gates), which achieved the highest Dice among seven segmentation models
- **STM32 multi-parameter health-monitoring terminal** (STM32F429, FreeRTOS, TouchGFX): PPG (HR/SpO2), blood pressure, ECG channel, skin temperature, plus an IMU fall-detection alarm subsystem
- **Qt intelligent infusion monitoring system**: drip-rate calculation, bubble detection and live dashboards
- **ECG denoising** with FIR, IIR and MODWT wavelet methods (MATLAB)
- **EMG and ultrasound signal analysis** (MATLAB)
- **CT brain image processing**
- **Analog signal-conditioning circuit** design and simulation
- **3D-printed heart models**: Normal, VSD, HCM, DCM comparison
